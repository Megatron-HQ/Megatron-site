# Megatron v0.4.0 website sync

The site started at `f151f4a`, with desktop v0.3.0 (`5d9c9c1`) in the interactive preview and on the Windows download button. That renderer already included the left rail. The [v0.4.0 release](https://github.com/Megatron-HQ/Megatron/releases/tag/v0.4.0) adds MCP servers between Plugins and Usage, and a separate MCP servers panel inside Usage. The new snapshot pins `08a04051443b5350cc84df4739608a71419248e3`, which matched desktop `main` at the time of the review. The [tracking issue](https://github.com/Megatron-HQ/Megatron-site/issues/2) records the treatment of the 32 commits in the [release range](https://github.com/Megatron-HQ/Megatron/compare/v0.3.0...v0.4.0).

## Verification

- Production interaction QA covered keyboard navigation, MCP connection checks and declaration actions, all three What's New destinations, and the MCP analytics handoff. All eight Usage views, both macOS copy controls, the Windows link, and the no-JavaScript install panels passed.
- The responsive sweep captured 285 states at 375, 768, 1024, and 1440px with zero scenario failures, horizontal overflow, or browser errors.
- The original v0.4.0 Electron renderer and the browser preview matched in 108 pixel comparisons at 1200×720 and 860×600 using identical sample data. The preview stylesheet keeps long Source labels inside their cells and the host tabs fit on one line at 375px.
