NEXT

Bring your projects into view.

On first launch, Megatron finds your global and plugin skills. Open Settings → Project folders → Manage… to include your project repositories or parent folders.

Existing local Claude Code data populates the app. Plugin actions and Resident tax measurements also require the claude CLI on your PATH.

Megatron refreshes when its window regains focus, after folder grants change, and after plugin actions. Use Settings → Rescan now for a manual refresh. Settings shows scan progress and any sources that could not be refreshed, including usage history. Missing project folders keep their cached data and are listed separately from scan failures.

A FEW GOOD QUESTIONS

Before you
get started.

Is this a replacement for Claude Code?

Megatron runs alongside your existing Claude Code workflow. It gives you visibility into skills, plugins, and local session usage. Claude Code remains where you do the work.

Will it change my skill files?

Skill inspection does not edit definitions or execute skill scripts. Resident tax runs Claude Code’s local /context command, which can start configured SessionStart hooks and MCP servers. Plugin management uses Claude Code’s own CLI commands, which may access the network. Inventory and usage analysis run locally.

Will my activity history stay available?

Megatron keeps a local usage archive across scans and cache rebuilds, without storing prompt text in that archive. It retains activity already observed when Claude Code removes older source files. History deleted before Megatron saw it cannot be recovered. The History panel shows annual summaries, a yearly calendar, and a monthly project timeline. Coverage notes separate missing history from days with no activity; streaks count consecutive observed days with prompts. A day can still show token details when its prompt history is unavailable. Incomplete source scans preserve the previously archived history.

What do the token totals include?

Total tokens processed includes input, output, cache reads, and cache writes. Thinking is included in output. Figures for a time period are estimated allocations of recorded session totals; missing and undated token data are identified separately. Compact values show their exact counts on hover or keyboard focus; those counts retain the same estimation limits.

How is resident context measured?

Resident tax runs Claude Code’s /context from an empty folder to measure your global baseline, excluding project instructions, skills, and MCP servers. It measures on first open each launch and again when you choose Refresh. Deferred tools and the autocompact buffer are shown separately. Category tables come from /context; other details read the first request of your newest interactive Claude Code 2.1.300+ session on demand, without storing it. Those session details can include project configuration. The website preview uses synthetic examples throughout.

How accurate are the cost figures?

Megatron uses cost information recorded by Claude Code. Time and skill breakdowns are approximate allocations. They represent estimated API-equivalent usage, not subscription charges or invoices. Missing data is shown as a coverage gap.

Which platforms and tools are supported?

The desktop app targets macOS and Windows and can currently be run from source. It is specifically built for Claude Code. Skills from other tools and Linux distribution are outside the current scope.

Is Megatron free?

Megatron is currently free and open source under the MIT license. You can inspect the code, run it locally, and contribute on GitHub.

Why isn’t my project showing up?

Project folders require an explicit grant. Open Settings → Project folders → Manage…, add your repository or parent folder containing multiple projects, and rescan if needed. Analytics also depend on the local history and transcripts retained by Claude Code. Automatic discovery skips temporary and build directories; explicitly granting a repository inside one still includes it.
