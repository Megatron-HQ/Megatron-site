A FEW GOOD QUESTIONS

Before you
get started.

Is this a replacement for Claude Code?

Megatron runs alongside your existing Claude Code workflow. It gives you visibility into skills, plugins, and local session usage. Claude Code remains where you do the work.

Will it change my skill files?

Skill inspection and analytics are read-only. Megatron does not edit skill definitions or execute their scripts. Plugin management is a separate capability that uses Claude Code’s own CLI commands.

How accurate are the cost figures?

Megatron uses cost information recorded by Claude Code. Time and skill breakdowns are approximate allocations. They represent estimated API-equivalent usage, not subscription charges or invoices. Missing data is shown as a coverage gap.

Which platforms and tools are supported?

The desktop app targets macOS and Windows and can currently be run from source. It is specifically built for Claude Code. Skills from other tools and Linux distribution are outside the current scope.

Is Megatron free?

Megatron is currently free and open source under the MIT license. You can inspect the code, run it locally, and contribute on GitHub.

Why isn’t my project showing up?

Project folders require an explicit grant. Open Settings → Project folders → Manage, add your repository, and rescan if needed. Analytics also depend on the local history and transcripts retained by Claude Code.
